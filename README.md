# Ejercicio - Alumnos y Cursos 
### Funcionalidades:
- **Gestión de Alumnos:** Creación de objetos Alumno con atributos como nombre, apellido, matrícula y carrera.
- **Gestión de Cursos:** Un curso puede contener múltiples alumnos mediante el uso de `ArrayList`.
- **Operaciones:** - Agregar y eliminar alumnos de un curso.
  - Validar si un alumno pertenece al curso mediante su número de matrícula.
  - Visualización completa del curso y sus integrantes mediante el método `toString()`.
